Before reporting a problem

  • Confirm you are using the latest available test or production build.
  • Restart the game and, if appropriate, your device.
  • For purchase problems, do not repeatedly purchase the same item; report the issue first.
  • Never post payment-card numbers, passwords or other sensitive credentials in a public issue.
